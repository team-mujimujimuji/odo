# 폰 동반 화면 목업 생성기 (`tools/phone-mockup/`)

`render.py`는 오도 폰 동반 화면 목업 6장(연결·연결됨 홈·트립 요약·공유 카드·업적·차고)을 Pillow만으로 그려 `docs/phone-mockup/`에 PNG와 `manifest.json`을 쓴다. 다음 값은 앱 소스에서 정규식으로 직접 읽는다: 색(`OdoTokens.kt`의 OdoNight), 차종·색·부품(`VehicleType.kt`·`CosmeticCatalog.kt`), 레벨·칭호·해금 표(`LevelTable.kt`), 일일 상한(`Thresholds.kt`), 차 화면과 겹치는 문구(`strings.xml`), 업적(`achievements.json`), 3D 미니카 hero 플레이트(`assets/minicar`, `OdoVehicle`과 같은 틴트·합성). `screens.json`에는 차 데모와 맞춘 데모 값(Lv 5 · 안전 65 km · +300 XP · 업적 5/12 · 체리)과 폰에만 나오는 문구만 둔다. 실행 명령은 `sh tools/phone-mockup/fetch_fonts.sh && python3 -I tools/phone-mockup/render.py`이고 Pillow가 있어야 한다. libraqm이 있으면 표 숫자(tnum)까지 맞춰 그린다(없어도 그려지지만 숫자 폭이 달라져 PNG가 달라진다). 시각을 읽지 않고 카메라 잡음도 고정 시드라서 Pillow와 글꼴이 같으면 PNG가 바이트까지 같다. 검증한 조합은 Pillow 12.3.0·13.0.0(둘 다 raqm 사용)이고, 두 버전의 PNG는 같으며 `manifest.json`의 `pillow` 값만 다르다. 입력·글꼴·출력의 sha256은 manifest에 남는다. 글꼴은 저장소에 넣지 않고, 태그를 고정한 URL에서 받아 sha256을 확인한다: Noto Sans CJK KR Sans2.004 Medium/Bold(SIL OFL 1.1, https://github.com/notofonts/noto-cjk), Roboto v2.138 Medium/Bold(Apache 2.0, https://github.com/googlefonts/roboto-2). 기기 프레임과 아이콘은 직접 그린 일반 도형이라 제조사 로고나 상표가 없다. 트립·뒤로 아이콘만 폰 전용이고, `Icons.kt`와 같은 2dp 선으로 그렸다. QR은 자체 v3-M 인코더로 만든 데모 토큰이다(`sha256(tokenSeed)` 앞 16바이트, 실제 페어링 토큰이 아니다). 실명·계정·위치 기록은 넣지 않는다.
