# 폰 동반 화면 목업

차(Pleos Connect) 화면과 함께 쓰는 휴대폰 동반 앱의 화면 목업이다. 1차 범위에는 폰 앱이 없어서, 차 앱과 같은 토큰·문구·미니카 에셋으로 그린 정지 화면으로 연동 흐름을 보여 준다. 캔버스는 390×844 dp를 3배로 그린 1170×2532 px다. 기기 프레임은 직접 그린 일반 프레임(모서리 48 dp, 베젤 12 dp, 펀치홀 1개)이고 제조사 로고가 없다.

데모 값은 차 앱 데모를 끝까지 재생한 상태와 같다. DemoSeed(820 XP · 42 km · 업적 3)에서 출발해 11월 9일 트립(안전 65 km · +300 XP)을 마치면 1120 XP로 Lv 5가 되고, 휴게소에서 10분 머물러 업적이 5개가 된 뒤, 마지막에 색을 체리로 바꾼다. 레벨·칭호·다음 레벨 XP는 `LevelTable.kt`로 계산하고, 차와 겹치는 문구는 `strings.xml`에서 그대로 가져온다.

## 다시 만들기

```sh
sh tools/phone-mockup/fetch_fonts.sh          # 글꼴 4개, sha256 확인 (저장소에는 안 넣음)
python3 -I tools/phone-mockup/render.py       # → 이 폴더의 PNG 6장 + manifest.json
```

생성기 설명과 입력 목록은 [`tools/phone-mockup/README.md`](../../tools/phone-mockup/README.md)에 있다. 같은 Pillow(libraqm 포함)와 같은 글꼴이면 PNG가 바이트까지 같다. `manifest.json`에 입력 파일, 글꼴과 출력의 sha256, QR 형식이 남는다.

## 출처·개인정보

- 글꼴: Noto Sans CJK KR Sans2.004([SIL OFL 1.1](https://github.com/notofonts/noto-cjk)), Roboto v2.138([Apache 2.0](https://github.com/googlefonts/roboto-2)). 이미지 안에 글자로만 쓰고 글꼴 파일은 배포하지 않는다.
- 미니카, 아이콘, 기기 프레임은 이 저장소의 스크립트로 직접 그렸다(`tools/minicar/`, `render.py`). 제조사 로고와 상표는 없다.
- QR(`odo-link:v1:…`)은 데모 토큰이라 실제 연결에는 쓸 수 없다.
- 실명·연락처·계정·차량번호·위치 기록은 넣지 않았다. 폰에 오는 것은 차가 공유하는 집계값(안전 km · 레벨 · 업적)뿐이고, 원시 차량 신호와 위치 기록은 차 밖으로 나가지 않는다.
